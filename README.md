## SSH7 是什么

一个专门用来连服务器的桌面客户端。打开就能连、连上就能干活，
终端、文件、传东西在同一个窗口里，不用来回切换。

它和老项目 [LuciSSHClient](https://github.com/ai-anunnaki/LuciSSHClient) 做的是同一件事，
但重写了一遍 —— 启动更快，占用更少，界面更安静。

## 它能做什么

### 连接

- **两种认证** —— 密码、私钥；带口令的加密私钥也能直接用
- **连之前先测一下** —— 连通性测试会告诉你握手花了多久，一眼分清「网络不通」和「密码错了」
- **换过机器的密钥会被拦下** —— 第一次连接时记住这台服务器的密钥，之后一旦变了就拒绝连接
- **断了会自己接回去** —— 网络抖一下、远端重启，会话自动重连三次；连不上就说清楚原因
- **你说断就断** —— 主动点的「断开连接」不会又偷偷连回来
- **关掉标签就真的断了** —— 连接被彻底回收，不留悬挂的进程

### 会话

- **多会话标签页** —— 同时连好几台，标签一切就换，互不干扰
- **标签能改名、能排序** —— 双击标签就地改名，按住横向拖动调整顺序
- **一台机器可以开多条** —— 主机行上悬停出现「＋」，随时另开一个会话
- **克隆会话** —— 用同一套凭据开一条新连接，省得重填
- **一台机器一个窗口** —— 右键「在新窗口打开」，开发机和生产机分开放

### 主机管理

- **分组** —— 侧边栏按分组归拢机器；分组能新建、改名、删除、拖动排序，机器也能直接拖进别的组
- **建分组就在原地建** —— 点「＋ 分组」，列表最下面直接多出一行，光标就在里面
- **右键分组直接建连接** —— 分组字段已经填好那个组
- **只登记不连接** —— 「仅保存」把机器记进列表，密码照样加密存着，之后再连
- **破坏性操作一律先问** —— 删主机、删分组、关会话、删远端文件、恢复默认，都会先弹框说清后果
- **点一下不会乱连** —— 单击只是选中，要连得点 ＋ 或用右键菜单

### 终端

- **完整终端** —— 256 色、支持调整窗口尺寸、链接自动可点、回滚 8000 行
- **每个会话一个独立终端** —— 切换标签互不干扰，切回来自动对齐尺寸
- **字号与界面缩放随手调** —— 终端字号 9~24px、界面缩放 85%~130%，快捷键随时加减
- **快捷键不抢戏** —— 除字号快捷键外，其余按键原样交给远端程序

### 文件

- **文件管理** —— 浏览远端目录、新建目录、上传、下载、递归删除
- **拖过去就传** —— 把本地文件拖进终端区或文件面板即可上传；拖文件夹会递归建出同样的目录结构
- **面板跟着终端走** —— 终端里 `cd` 到哪，文件面板跟到哪；自己翻目录不会被拽回，一键跳回
- **面板宽度可拖** —— 拖左边缘拉宽看全文件名，最宽占屏幕一半，宽度会记住
- **传完就收** —— 进度条成功后 3 秒自动消失；失败的留着让你看清原因

### 安全

- **密码与私钥口令只进加密库** —— 加密后存在本机，**绝不落盘明文**；
  不依赖系统钥匙串，不弹窗，各平台行为一致
- **主机列表不含任何秘密** —— 里面只有地址、端口、用户名这些基本信息
- **私钥内容不出现在任何日志或提示里**

### 其它

- **实时工作目录** —— 自动跟踪远端当前目录，标签上直接显示路径
- **界面重绘不闪** —— 状态点颜色区分：绿=已连接，红=失败，灰=已断开

## 软件特点

- **安静** —— 不塞功能、不堆名词、不弹广告。屏幕上只有你正在做的事
- **明确** —— 错误提示只说人话，不甩错误码；做错事之前一律先问一句
- **顺手** —— 能拖的地方光标就是抓手，拖起来整个窗口都跟着变抓手，不会在半路散掉
- **一致** —— macOS 和 Windows 上装出来是同一套行为，同一份数据格式
- **克制** —— 一个界面只有标题栏、侧边栏、标签栏、终端区、文件面板，没有多余的一层

## 安装

### macOS

下载 [Releases](https://github.com/chuaker7/SSH7/releases) 里的 `.dmg`，拖入「应用程序」。

| 文件 | 适用机器 |
|---|---|
| `SSH7_x.y.z_aarch64.dmg` | Apple Silicon（M1/M2/M3/M4） |
| `SSH7_x.y.z_x64.dmg` | Intel Mac |
| `SSH7_x.y.z_universal.dmg` | 两种架构通吃 |

首次打开若提示「无法验证开发者」，在「系统设置 → 隐私与安全性」中点「仍要打开」即可。

### Windows

下载 [Releases](https://github.com/chuaker7/SSH7/releases) 里的 `-setup.exe`，双击安装。

| 文件 | 适用机器 |
|---|---|
| `SSH7_x.y.z_x64-setup.exe` | 64 位 Windows（Win10 / Win11） |

装的时候可能会遇到两件事，都不是故障：

| 现象 | 处理 |
|---|---|
| SmartScreen 弹窗「Windows 已保护你的电脑」 | 安装包没有做代码签名。点「更多信息」→「仍要运行」 |
| 提示缺少 WebView2 | Win11 自带；Win10 一般随 Edge 已经有了。真没有的话安装程序会联网自动补装 |

### Linux

代码每次提交都会在 Linux 上编译并跑完整套测试，装包还在路上。

## 五分钟上手

1. 点侧边栏的 **＋ 连接**，填上主机、用户名和密码
2. 想先确认网络通不通，就点 **连通性测试**
3. 点 **连接** —— 右上角多出一个会话标签，终端连上了
4. 想传东西：点侧边栏 **文件** 打开文件面板，或者直接把本地文件**拖进终端区**
5. 想让这台机器下次还在：勾上 **保存**

## 从源码构建

需要 [Rust](https://rustup.rs/) 1.82+、Node.js 20+。

```bash
git clone https://github.com/chuaker7/SSH7.git
cd SSH7
npm install

npm run tauri dev     # 开发模式
npm run tauri build   # 打包当前平台
```

产物在 `src-tauri/target/release/bundle/`。
