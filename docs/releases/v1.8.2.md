SSH7 v1.8.2 —— 跨平台 SSH 客户端

下载对应架构的 `.dmg`，拖进「应用程序」即可。

## 这一版修了什么

- **断线之后终于能重连上了**：之前会话一断，点「重试」**每次都失败** —— 前端没把
  「用哪把钥匙」告诉后端，后端取不到密码，只能报认证失败。现在重连会带上主机 id
  和私钥路径，能正常接回去。

- **断线的提示页重做了**：不再是一行灰字。断开时终端上会盖一层浮层 —— 正在重连时是
  一圈慢慢转的信号弧，断了之后是一枚被划掉的信号图标，并且写清楚**为什么没连上**
  （比如「认证失败：密码错误，或本机没有这台机器的凭据」），底下两个按钮：
  **重新连接** / **关闭标签**。

- **重连有动画了**：正在重连时信号弧转着、下方三点呼吸；三次都没接上就停下来等你决定。

- **自己会接回去**：意外断线（网络抖一下、远端重启、会话超时）会自动重试三次 ——
  立刻试一次，再等 1.2 秒、3 秒各试一次。接上了标签不挪位置，**终端里断线前的屏幕
  内容原样留着**。

- **你主动断开的，它不接**：右键标签 →「断开连接」之后，它就老实断着，不会自己又
  连回来。

- **一次断线只开一条重连**：之前监听器会重复注册，一次断线能同时开出好几条重连
  循环，把服务器连接数刷高。现在每个会话只允许一条重连。

- **远端 history 里不再留内部命令**：之前每连一次服务器，远端 shell 的 history 里就
  会多出两行看不懂的内部代码（`__ssh7_osc7`、`stty echo`）—— 屏幕上看不见，但它确实
  进了你的历史记录。现在 bash 会在装完钩子后自己抹掉（连你自己关掉 history 的情况
  也不会误删你的命令），zsh 借助「忽略空格」做到基本无痕，fish 保持原样。

## 已经用过的旧版本，怎么清掉历史里的痕迹

对已经连过的服务器，在服务器上执行：

```bash
# 当前会话（倒着删 —— 删掉靠前的那条会让后面那条的编号往前挪）
for i in $(history | grep -E '__ssh7_osc7|stty echo' | awk '{print $1}' | tac); do
  history -d "$i"
done

# 已经写进 ~/.bash_history 的那份
cp ~/.bash_history ~/.bash_history.bak
grep -vE '__ssh7_osc7|stty echo' ~/.bash_history.bak > ~/.bash_history
```
