SSH7 v1.9.0 —— Windows 版正式发布

这一版起，SSH7 在 macOS 和 Windows 上都能用了。

## 这一版新增了什么

- **Windows 版正式发布**：从本页下载 `-setup.exe`（NSIS 安装包），双击安装。
  - **界面需要 WebView2**：Win11 自带，Win10 随 Edge 一般已经有了；
    真缺的话，安装程序会联网自动补装。
  - **安装包没有做代码签名**，Windows SmartScreen 会拦一下 ——
    点「更多信息」→「仍要运行」即可。
  - **主机列表与凭据库**放在 `%APPDATA%\com.chuaker7.ssh7\`，
    与 macOS 上是**同一套格式**。
- **两边的功能完全一致**：主机分组、标签排序、SFTP 文件面板、拖拽传文件、
  断线自动重连、密码加密存本机 —— 在 Windows 上一样有，一样顺手。
- **两个平台可以同一天发布**：macOS 与 Windows 各自构建、各自打包，
  最后汇总到同一个页面 —— 以后不会再出现「一个平台好了、另一个平台还在等」。

## 升级说明

- 从 v1.8.2 直接升级即可，主机列表与凭据库不受影响。
- v1.8.2 的两处修复（远端 history 不再留内部命令、断线后能自己接回去）依旧有效。
- macOS 用户**什么都不用变** —— 这一版 macOS 端的内容和 1.8.2 一致。
