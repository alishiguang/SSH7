SSH7 v1.9.0 —— 跨平台 SSH 客户端

下载对应平台的安装包即可。

## 这一版新增了什么

- **Windows 版正式发布**：从本页下载 `-setup.exe`（NSIS 安装包），双击安装。
  - 界面跑在 **WebView2** 上：Win11 自带，Win10 随 Edge 一般已经有了；真缺的话
    安装程序会联网自动补装。
  - 安装包**没有做代码签名**，Windows SmartScreen 会拦一下 ——
    点「更多信息」→「仍要运行」即可。
  - 凭据库与 macOS 上是**同一套格式**：一个加密文件 + 一个密钥文件，
    放在 `%APPDATA%\com.chuaker7.ssh7\`。
- **发布流水线按平台分治**：macOS 与 Windows 各自构建、各自上传产物，
  最后由一个汇总 job 统一发布成同一个 Release。两个 job 同时往一个 Release 里
  塞文件会互相覆盖 —— 现在不会了。
- **产物自检也跟着分平台**：macOS 上仍然拿临时 `HOME` 跑产物，看它实际建出哪个
  数据目录（直接读二进制内嵌的标识符）；Windows 上数据目录走的是 WinAPI 的
  known-folder，环境变量重定向不了，于是改用**编译期自检**钉住同一个标识符 ——
  读的是同一份内嵌上下文，一样是编译期的事实来源。
- **CI 补上 Windows 的打包任务**：Windows 上编译不过、测试不过，
  在合并前就暴露，而不是等打标签才发现发不出去。

## 升级说明

- 从 v1.8.2 直接升级即可，主机列表与凭据库不受影响。
- v1.8.2 的两处修复（远端 history 不再留内部命令、断线后能自己接回去）依旧有效。
- macOS 用户**什么都不用变** —— 这一版对 macOS 只是流水线改造，产物内容一致。
